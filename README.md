# Anouar Guermazi: engineering portfolio

**Live site: [anouarguermazi.framer.website](https://anouarguermazi.framer.website/)**

Engineering student at CentraleSupélec working on control, robotics and machine learning. The live site presents my projects with technical reports and interactive simulations:

- [Open Duck Mini](https://anouarguermazi.framer.website/projects/open-duck-mini): open-source bipedal robot, learning-based locomotion (in progress)
- [Cubli](https://anouarguermazi.framer.website/projects/cubli): reaction-wheel self-balancing cube, PID and LQR control
- [Tuned mass damper](https://anouarguermazi.framer.website/projects/tmd-active-control): vibration damping of a building model

`Portfolio_High-Tech_Anouar_Guermazi.html` is an earlier static version of the site, kept for reference.
